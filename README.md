# Birdbrain

A guess-the-bird game built on [huashu-bird-sticker](https://github.com/alchaincyf/huashu-bird-sticker) (11,011 species, CC BY 4.0), with an India-first set of decks.

## Run it

Open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8765
```

## Hosting

The site is plain static files, so any static host works. Files to publish: `index.html`, `favicon.ico`, `data/`, `assets/`, `manifest.webmanifest`
(`CNAME` and `.nojekyll` are for GitHub Pages). Target address: https://birdbrain.indianbirds.org

Sticker images are loaded from `raw.githubusercontent.com` (with jsDelivr as a fallback). That is fine for a launch, but if traffic grows, copy the stickers
to your own storage or put a CDN such as Cloudflare in front.

The game name lives in `const BRAND` in `index.html`, plus the `<title>`, `og:` tags and `manifest.webmanifest`.

## How it works

- `index.html` is the whole game (no build step, no framework).
- Home screen = ready-made **decks** (defined in the `DECKS` array). Tapping one opens a difficulty sheet (Easy / Medium / Hard).
- "Build your own deck" is a 3-step filter: where, what kind of bird, fine-tune.
- `data/birds-data.js` is a compact index generated by `build_data.py` from the upstream `species.json` and `names.csv`:

  ```bash
  git clone --depth 1 --filter=blob:none --sparse https://github.com/alchaincyf/huashu-bird-sticker upstream
  (cd upstream && git sparse-checkout set data)
  python3 -I build_data.py upstream/data
  ```

## Daily Birdbrain

The same 10 birds for everyone each day (the day changes at midnight IST), one try per player, with a streak and a shareable result.

- `data/daily.js` holds four frozen lists of bird ids (3 well-known, 4 Indian, 2 from the world, 1 tricky finish). Each day takes the next birds from each list, so nothing repeats until a list runs out. The lists are written once by `build_daily.py` with a fixed seed, so rebuilding the bird data never changes a day's birds.
- The wrong answer choices come from a seeded random generator, so they are identical on every device.
- Progress and the streak are saved in the player's browser only (`birdbrain.daily.v1`, `birdbrain.dstreak.v1`). Leaving mid-game keeps the answers already given.
- See what is coming: `python3 build_daily.py --preview 14`. Change `START` or the lists, then run `python3 build_daily.py` (this rewrites `data/daily.js`; do it before launch, not after, or the day numbers shift).
- On localhost, `?day=2026-11-20` previews another day.
- Stats: daily games are recorded with deck `daily` (title "Daily #N"), so they show up in the admin decks table.

## Quick games

Two short games on the same bird data, shown under "Quick games" on the home screen. Both are 10 rounds, no sign-in, and end with facts about the birds that were shown.

- **Which is heavier?** Two birds, tap the heavier one. The weight gap shrinks each round (about 30x down to 1.7x). Weights are average adult mass from AVONET. Link: `#heavier`.
- **Odd one out.** Four birds, three share something and one does not (family, look-alikes, diet, habitat, size, conservation status, migration). A round is only used when exactly one bird can be the odd one out on every trait in the data. Link: `#oddone`.
- Stats: logged as decks `heavier` and `oddone`. They count in the totals but are kept out of the difficulty chart and average accuracy. Per-round results go to the `mode_stats` table (`migrations/004_quick_games.sql`) and show in the admin "Quick games" section.

## India data (approximate)

- "India" and the Indian sub-regions are matched from each bird's range text (India, Indian states, Himalayas, Nepal, "Pakistan to ...", and so on). It finds about 1,100 species, a bit fewer than the real checklist.
- "Winter visitors" = birds whose wintering range mentions India but whose breeding range does not, and that migrate.
- The "Everyday Indian birds" deck is a hand-picked list of 63 well-known birds (`EVERYDAY` in `build_data.py`).
